## 🚀 Selected Projects

Here are some of the enterprise and product experiences highlighted in my portfolio.

### 🌐 GoFintel — United Nations

A data analytics platform associated with the United Nations Office of Counter-Terrorism and UNCCT, focused on detecting and countering money laundering and terrorist financing.

**Technologies:** React.js · TypeScript · PrimeReact · D3.js · Docker · CI/CD

[Explore the live project](https://unite.un.org/)

### 📈 Kalshi — Regulated Event Exchange

Contributed to high-concurrency financial interfaces, real-time order book experiences, micro-frontends, and automated testing for a regulated event-trading platform.

**Technologies:** Next.js · React · TypeScript · Tailwind CSS · Material UI · Jest

[Visit Kalshi](https://kalshi.com/)

### 🛍️ NTUC FairPrice — E-Gift Voucher Platform

Worked on an enterprise e-commerce gift voucher experience involving secure checkout and redemption workflows, with automated end-to-end testing and code quality practices.

**Technologies:** React · Next.js · TypeScript · Cypress · SonarCloud

[Explore FairPrice](https://www.fairprice.com.sg/)

### 🛡️ Emgage — Cybersecurity Workspaces

A configurable workspace experience for cybersecurity professionals, with customizable widgets and integrated document editing capabilities.

**Technologies:** React · Next.js · TypeScript · Micro-Frontends

[Visit Emgage](https://emgage.com/)

### ☁️ CloudRemedy — Cloud Governance

A cloud governance and compliance reporting product with data protection metrics, multi-cloud progress tracking, and interactive visualizations.

**Technologies:** React.js · TypeScript · GraphQL · D3.js · Material UI

[Visit CloudRemedy](https://cloudremedy.io/)

### 🧩 Verify Trusted — Review Aggregation

A review aggregation widget that combines customer feedback from multiple platforms into a unified display for businesses.

**Technologies:** Next.js · React · TypeScript · Google Maps API · Tailwind CSS

[Explore Verify Trusted](https://www.verifytrusted.com/)
